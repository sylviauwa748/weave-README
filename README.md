## What Weave Does


Weave is a concurrency intelligence platform for Java that builds a semantic model of concurrent execution, uses that model to perform static analysis, simulation, runtime verification, and explainable intelligence to help developers understand, predict, and eliminate concurrency problems before and during execution.
