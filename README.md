## What Weave Does


# Weave is a concurrency intelligence platform for Java that builds a semantic model of concurrent execution, uses that model to perform static analysis, simulation, and runtime verification, and presents explainable, actionable guidance through deterministic algorithms enhanced by AI-assisted explanations.
